Вариант 14. Погода

Задание 1. Ввести n (1..31) — число дней. С помощью for вывести температуру каждого дня по простой модели t = 5 + i % 7 и найти среднюю температуру.

Задание 2. С помощью while вводить температуру до значения 999, которое завершает ввод. Посчитать число корректно введённых температур и число отрицательных значений.

Задание 3. Через do-while запросить влажность от 0 до 100. После корректного ввода вывести, сколько процентов до 100 осталось.

Задание 4. Ввести days и hours (1..8). Вложенными циклами вывести сетку наблюдений day-hour и общее количество измерений.
